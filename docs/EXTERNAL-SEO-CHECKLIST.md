# External SEO and local-search checklist

## Before requesting indexing

- Verify the production property in Google Search Console and submit `https://maidathome.com.au/sitemap.xml`.
- Inspect the homepage, each service URL and the 19 priority area URLs in Search Console after deployment.
- Confirm the Google Business Profile website URL, primary category, opening hours, phone number and service areas match this site.
- Use a verified review total only. Never add a review count or rating to structured data without a source that can be checked.

## Ongoing authority work

- Request genuine Google reviews after completed bookings; do not incentivise or script misleading reviews.
- Keep GBP posts and service descriptions aligned with current services and service areas.
- Build relevant Melbourne citations and partnerships where there is a real relationship.
- Review query data monthly, then improve the relevant service or blog page instead of publishing near-duplicate suburb content.

## Migration guardrail

Legacy copied HTML is intentionally absent from the repository. The Astro source under `src/` is the only publishable site source. Preserve redirects for any historical `.html` URLs in hosting configuration when real historic URLs are confirmed.
